```

```
**Bold text** - Navy color
*Italic text* - Slanted

## 💫 Interactive Elements

### Hover Effects
```
Card hover:        Shadow expands, border changes to teal
Link hover:        Underline appears
Button hover:      Background darkens slightly
Category hover:    Scale increases (105%)
```

### Scroll Effects
```
TOC:               Active heading highlighted in teal
                   Smooth scroll to section on click
                   
Article:           Progressive disclosure
                   Smooth reading experience
```

### Click Feedback
```
Share button:      Menu slides down
Copy link:         ✅ Success message appears
Category filter:   Immediate article filtering
Search:            Real-time results update
```

## 🔗 Navigation Flow

```
Home Page
    ↓
Blog Listing (/blog)
    ↓ (click article)
Article Page (/blog/[slug])
    ↓ (click related)
Another Article
    ↓ (back button)
Blog Listing
    ↓ (category filter)
Filtered Results
    ↓ (search)
Search Results
```

---

## 📊 Data Flow

```
User Request
    ↓
Next.js Route
    ↓
API Route (or Direct Prisma)
    ↓
Database Query
    ↓
Data Processing (read time, related)
    ↓
React Component
    ↓
Markdown Rendering
    ↓
Styled HTML
    ↓
User Display
    ↓
View Count +1
```
